# 更新说明（Changelog）

按时间倒序记录 DSH Remote / DSH Suite 的变更。版本号仍在 `0.8.0` 上迭代，尚未发布新的正式版本号。

---

## 0.8.0 · 第二轮改进（2026-08-30 ~ 08-31）

### Windows 桌面

- 重做启动体验：移除独立启动窗，改为**主窗口内的无缝启动覆盖层**。冷启动时中央显示无底图标动画（琥珀光点沿白色波浪滑行），WebView2 隐藏并在后台加载页面；后端就绪且页面加载完成后，图标收缩淡出，一次性显示成品页面，菜单（手机互联 / 设置文件 / 启动日志）随之出现。
- 启动失败路径：中央错误文字 + 重新启动 / 查看日志 / 退出，30 秒兜底；热启动直接进入界面。
- 补齐深色 UI：下拉菜单自定义深色渲染，配对码弹窗深色化（标题栏、文本框滚动条、按钮布局），进程级深色模式。
- 启动页测试由 `SplashTests.cs` 更名为 `MainOverlayTests.cs`（消息循环模式，防挂死），构建脚本同步更新。

### 图标统一

- 桌面 exe、启动动画、手机 PWA、Android 启动器统一为同一视觉语言：黑底圆角卡 + 单一柔和白色波浪 + 波峰琥珀光点，去掉了此前渐变波浪的“亮暗分段”观感。
- 修正矢量波浪贝塞尔控制点方向（先峰后谷）。

### 用量与峰谷规则（重要修正）

- 按官方 2026-08-17 规则重写峰谷判断：**北京时间周一至周五 9:00–12:00、14:00–18:00 为高峰，其余时间（周末全天、午休、夜间）为空闲，空闲价格为高峰的一半**。
- 全链路替换：`desktop/linux/dsh-status.sh` 输出新的 schedule 结构（`timezone` / `utcOffsetMinutes` / `weekdaysOnly` / `peakWindows`），`src/usage.js` 白名单校验同步升级并透传 `pricingNote`；手机 PWA、Vercel 静态、Android assets 同步更新。
- 新增 `v4-flash-vision-exp` 定价（同 `v4-flash`）；未知模型返回带提示的空价格而非错误。
- 时段文案统一为「峰时 工作日 9:00–12:00 / 14:00–18:00 · 其余谷时」；`test/usage.test.js` 重写为 13 个边界用例（午休、周末、凌晨、跨窗口等）。

### 手机端（PWA / Android）

- 用量详情卡片化：余额大数字轻字重 + 弹入动画、各计费行交错入场、时段行波浪小图标（峰/谷翻转）、触发条波浪呼吸、连接点呼吸动画。
- 时段图标与配色跟随新的峰谷规则。
- APK 重新构建并采用统一 wave 启动器图标（`DSH-Remote-v0.8.0-wave.apk`）。

### 文档与发布

- 新增本文件（`docs/CHANGELOG.md`）。
- 公开审计通过（141 文件 0 发现）后重新导出源码包，并在发布仓库新增 `codex/wave-icons` 分支待推送合并。
- Vercel `vercel/` 静态目录已同步本轮全部前端改动；生产部署由部署者自行执行。

## 0.8.0 · 首次发布（2026-08-28）

- 首个 0.8.0 发布提交：`feat: publish DSH Remote companion suite 0.8.0`。
- 套件化：远程互联、Windows 桌面壳、Linux 用量组件、可选 NovaTab 合入同一源码仓库。
- 端到端加密消息、Vercel/Redis 密文信箱、离线补收、持久化发送队列。

- 移动端 PWA：会话面板、任务控制、连接状态、用量面板。
- 热修复：relay 恢复与生命周期处理加固（`fix: harden relay recovery and lifecycle handling`）。
