## 2026-08-28 桌面安装与启动热修

经用户要求已覆盖本机旧桌面（提前完整备份），沿用私有配置和原 DR2。修正 WSL 简单发行版名不应额外加引号的兼容问题，以及中文系统中 stdout 必须显式 UTF-8 的启动就绪识别问题。
